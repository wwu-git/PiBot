# 1 · 安装与第一次使用

Pi Bot 是一个桌面应用：一群有名字的 Bot 在你自己的电脑上干活，可以私聊、拉群、跑例行任务、读写你指定的文件夹。聊天记录、设置和密钥都保存在这台电脑上；只有你选用在线模型时，对话内容才会发给你选的模型厂商。

## 系统要求

| 系统 | 安装包 | 说明 |
|---|---|---|
| macOS | `.dmg`（Apple 芯片 / Intel 各一个） | 需要 macOS 13 Ventura 或更高版本；应用内更新要求 Pi Bot 放在「应用程序」文件夹 |
| Windows | 安装程序 `.exe` | 64 位 Windows 10 / 11 |
| Linux | `.deb`（Debian / Ubuntu）、`.AppImage`（另有 `.tar.gz`） | 64 位 x86；Ubuntu 24.04 及以上请用 `.deb`。命令隔离需要 `bubblewrap` 和 `socat`；只有 AppImage 能在应用内更新 |

你还需要一个能用的模型：在线模型的 API Key、ChatGPT 计划，或在本机运行的模型（如 Ollama）。详见 [9 · 模型与密钥](09-models-and-keys.md)。

## 安装

从官网 [下载页](https://pibot.space/cn/download/) 下载对应系统的安装包。

### macOS

1. 打开下载的 `.dmg`，把 **Pi Bot** 拖进「应用程序」文件夹。
2. 从「应用程序」或启动台打开 Pi Bot。
3. Pi Bot 目前还没有经过 Apple 公证。如果系统提示无法验证 Pi Bot，先确认安装包是从官网下载的；决定继续时，先尝试打开一次，再到「系统设置 › 隐私与安全性」找到 Pi Bot，点「仍要打开」。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

Pi Bot 平时没有程序坞图标，关掉窗口后在菜单栏的托盘图标里还能找到它（见 [托盘与后台](#托盘与后台)）。

### Windows

1. 双击安装程序。安装向导是中英双语的。
2. 选择「只为我安装」或「为所有用户安装」，可以修改安装位置；默认会创建桌面和开始菜单快捷方式。
3. 完成页可以直接启动 Pi Bot。
4. 如果 Windows SmartScreen 拦住了安装程序，点「更多信息 › 仍要运行」。

卸载时你的数据会保留（聊天、密钥都在数据文件夹里，见 [12 · 更新与数据](12-updates-and-data.md)），要不要删除由你决定。

### Linux

**Debian / Ubuntu（`.deb`，Ubuntu 24.04 及以上推荐）**

1. 用 apt 安装，命令隔离依赖（`bubblewrap`、`socat`）会一起装上：`sudo apt install ./PiBot-*.deb`
2. 从应用菜单打开 Pi Bot，或以普通用户运行 `pi-bot`（不要用 `sudo` 或 root）。

安装包装到 `/opt/Pi Bot`，并加一个 AppArmor 配置 `/etc/apparmor.d/pi-bot`。Ubuntu 24.04 及以后默认限制非特权用户命名空间；这个配置让 Pi Bot（以及它启动的程序）可以创建进程沙箱需要的用户命名空间，做法和 Chrome、VS Code 的配置相同，不改任何系统设置。`sudo apt remove pibot` 会连同配置一起删掉，你的数据保留。`.deb` 不能在应用内更新，新版本照同样方式安装新的 `.deb`。

**AppImage（其他发行版）**

1. 给 AppImage 加上可执行权限：`chmod +x PiBot-*.AppImage`，然后运行它。
2. 安装命令隔离依赖（Bot 跑命令时用）：
   - Debian / Ubuntu：`sudo apt install bubblewrap socat`
   - Fedora：`sudo dnf install bubblewrap socat`
3. 用普通用户运行，不要用 `sudo` 或 root，也不要加 `--no-sandbox`。

如果 AppImage 因为用户命名空间限制无法安全启动，会显示一个说明页：建议改用 `.deb`，也给出可以手动添加的 AppArmor 配置；照其中一种做完再打开即可。

## 第一次打开：欢迎流程

第一次打开会走五步欢迎流程，随时可以点「上一步」返回。

### 1. 认识 Pi Bot

![欢迎页](../images/zh/welcome-intro.png)

这一页说明三件事：Bot 团队、数据留在你自己的电脑上、动手前先问你。在这里选择**语言**（跟随系统 / 中文 / English）和**外观**（浅色 / 深色 / 跟随系统），之后都能在设置里改。点「开始使用」。

### 2. 选择模型

「Pi 用哪个模型」有四个选项：

- **推荐**：跟着你选的语言走。中文界面推荐 **DeepSeek**（官方 API，已选好 DeepSeek V4.1 Flash，消息直接发给 DeepSeek）；英文界面推荐 **OpenRouter**（一个 Key 用很多模型，消息先发给 OpenRouter，再转给模型厂商）。粘贴 Key 后点「保存并测试」。

  ![推荐的模型来源](../images/zh/welcome-model-deepseek.png)

- **ChatGPT 计划**：用你的 ChatGPT 计划额度，不需要 API Key。点「通过 ChatGPT 继续」，在浏览器完成登录，再回到 Pi Bot 选模型（详见 [9 · 模型与密钥](09-models-and-keys.md#用-chatgpt-计划登录)）。

  ![欢迎流程里的 ChatGPT 计划](../images/zh/welcome-model-chatgpt.png)

- **本地 · Ollama**：先在这台电脑安装并启动 Ollama，下载一个模型，然后回到 Pi Bot 点「重新检测」。检测到服务后选择模型再继续。下图是尚未检测到服务时的界面。

  ![选择本地 Ollama](../images/zh/welcome-model-ollama.png)

- **用我的 API Key**：用 API Key、云端凭据或自定义地址连接。先在「厂商」里选一个，填 Key，点「保存并测试」，再选一个默认模型。

  ![用自己的 API Key](../images/zh/welcome-model-apikey.png)

  厂商列表按「常用」「聚合与网关」「云厂商」「推理加速」「本机与自定义」「其他」分组，可以输入名称搜索：

  ![厂商列表](../images/zh/welcome-providers.png)

Key 用这台电脑的系统密钥库加密保存，保存后不再显示。如果你已经在环境变量里设置了对应的 Key（例如 `DEEPSEEK_API_KEY`、`OPENROUTER_API_KEY`），这一页会提示检测到了，可以点「导入」。

**网络代理**：在部分地区访问 Google、OpenAI 等模型服务需要代理。在线模型的几种方式下面都有「需要代理？设置网络代理」，点开就能填代理地址；如果这台电脑正在用代理，会自动填进去，打开「使用代理」后才生效。连不上模型时，出错提示旁边也会直接给出「设置网络代理」。之后可以在 设置 › 通用 › 网络代理 里修改（见 [9 · 模型与密钥](09-models-and-keys.md#本地模型和自定义网关)）。

### 3. 先请一个 Bot 帮忙

![选第一个 Bot](../images/zh/welcome-first-bot.png)

选一个角色，它会和 Pi 一起出现在侧栏。点「更多角色…」可以看到全部内置角色（工程、产品与设计、数据与研究、内容与营销、办公与运营、通用）。不想选就点「跳过，先用通用助手」。

### 4. 系统权限（macOS）

如果你希望 Bot 能操作电脑上的应用（点按钮、截图），在这一步打开：

- **辅助功能**：按界面点按钮、填内容；截图点击时移动鼠标
- **屏幕录制**：截图（只裁到你允许的应用窗口）
- **自动化**：让 Bot 用脚本控制「系统事件」和「访达」

![欢迎流程可跳过，之后在设置的「操作电脑」里检查系统授权](../images/zh/settings-computer-use-1.png)

开启屏幕录制后如果没有生效，点「重启 Pi Bot」。不需要操作电脑就点「稍后再说」，以后可以在 设置 › 操作电脑 里再开。Windows 不需要额外权限；Linux 在 X11 下不需要，Wayland 下截图每次会话确认一次。

### 5. 认识你的主 Bot

![认识 Pi](../images/zh/welcome-meet-pi.png)

Pi 是你的主 Bot。点一个建议开始，或点「和 Pi 聊聊」进入主窗口。

### 托盘与后台

关闭窗口后，Pi Bot 继续在后台运行（例行任务照常跑），可以从托盘（Windows / Linux）或菜单栏（macOS）重新打开。要完全退出，用托盘菜单里的「完全退出（例行任务也停止）」。在 设置 › 通用 › 启动 里可以选择登录这台电脑时「不启动」「打开窗口」或「只在后台运行」，也可以关掉托盘图标。

### 灵动岛

Pi Bot 窗口不在最前面时（切到别的应用、最小化或关掉了窗口），Bot 干活时屏幕顶部中间会出现一条小胶囊：显示 Bot 的头像、名字、正在做的事和已经做了多久。几个 Bot 同时干活时，用上下箭头或滚轮 / 触控板上下翻；点一下就打开那个对话、群任务、例行任务或等你确认的卡片。它只显示名字和简短的标题（计划步骤、群任务名、例行任务名、确认卡标题），不显示消息内容或文件内容。

在 设置 › 通用 › 灵动岛 里可以：

- 打开或关闭灵动岛（默认打开）；
- 选择「头像和在做的事」或「只显示头像」（只显示头像时更小，鼠标移上去再展开）；
- 勾选显示哪些：私聊在干活、群任务步骤、例行任务、等你处理（默认全选）。

回到 Pi Bot 窗口时灵动岛自动收起。Bot 操作电脑时，顶部的操作提示优先，灵动岛暂时收起。灵动岛只在桌面端（macOS、Windows、Linux X11）提供，手机 App 没有；Linux 的 Wayland 会话不能把小窗固定在屏幕顶部，设置里会说明暂时用不了。
