# 13 · 隐私与安全

Pi Bot 的「大脑」在你自己的电脑上：聊天记录、设置、记忆和审计记录都留在本机。这一页说明什么留在本地、什么会发出去、发给谁，以及 Pi Bot 用哪些机制限制 Bot 能做的事。

## 什么留在本地

- 聊天记录、话题、附件
- Bot 的设置、人设、技能、记忆
- 例行任务和待办
- 操作记录（审计）、工作收据、改动检查点
- 本机日历、通讯录、Obsidian 知识库的内容（Bot 读取时按权限）

这些都在本机的数据文件夹里（位置见 [12 · 更新与数据](12-updates-and-data.md#数据保存在哪里)）。

## 什么会发出去

只有在你选择的情况下，数据才会离开这台电脑：

| 发给谁 | 发什么 | 什么时候 |
|---|---|---|
| 你选的模型厂商 | 对话内容、Bot 读到的相关文件片段和网页内容 | 用在线模型时。用本地模型（如 Ollama）时不出电脑 |
| 辅助模型的厂商 | 整理上下文、交接、翻译、提炼网页时的相关内容 | 你在设置里选了辅助模型时；默认跟随主模型 |
| 搜索服务 | 查询词 | Bot 联网搜索时；选哪个服务由你决定，免 Key 服务第一次还会确认 |
| Bot 访问的网站 | 普通的网页请求 | Bot 访问网站时；默认允许，可在权限里把「访问网站」改成「询问」 |
| 连接的服务（如 Notion、MCP） | 调用这些服务时需要的内容 | 你连接并给 Bot 用之后；写入和对外发送每次要你确认 |
| 中继服务 | 端到端加密的数据（中继看不到内容）、IP、连接时间、帧大小、在线状态 | 你打开「允许已配对设备连接」后，手机和执行端连接时 |
| STUN 服务（默认 Cloudflare） | 只查询你的公网 IP，不经手数据 | 已配对设备跨网络尝试直连时；可改成仅局域网直连 |
| roles.pibot.space | 请求角色库列表和你要安装的包，不带标识 | 你检查角色库或从角色库安装时 |
| pibot.space | 只读取新版本信息，请求里只有应用版本和平台，不带标识或使用数据 | 检查更新时（启动后不久，之后每隔几小时） |

用 ChatGPT 计划时，对话直接发给 OpenAI，不经过其他服务器。

完整清单（包括技能、插件、外部 Agent、手机通知等）以及每一项怎么关，见[对外连接清单](../../privacy/zh/outbound-connections.md)。

## 不加遥测

Pi Bot 不收集使用数据，不自动上报崩溃。反馈问题只有两种方式，都由你操作：在浏览器里打开预填好的 GitHub Issue（发不发布你决定），或导出脱敏日志自己发送。内容里不含聊天、文件内容或密钥。

## 密钥

![空的密钥输入界面，保存后由系统保护凭据](../images/zh/provider-openai.png)

- API Key、登录令牌、保存的账号密码都用系统密钥库加密保存在本机。
- 保存后界面不再显示 Key，只显示末尾 4 位。
- Key 不写日志、不发给界面、不给 Bot 和模型看。Bot 的浏览器用保存的账号密码自动登录网站时，Bot 和模型也看不到密码。
- 手机离线模式需要的模型 Key 只在你开启后同步到配对的手机，撤销或解除配对会清除。

## 限制 Bot 能做什么

- **权限判定**：Bot 调用的每个工具都经过权限判定，没有绕过的通道（见 [5 · 审批与权限](05-approvals-and-permissions.md)）。
- **工作位置**：默认只能写工作文件夹；工作位置外的写入逐次确认，只读参考不能写。
- **命令隔离**：macOS 和 Linux 上命令在沙箱里运行，联网受「允许的网站」名单限制。Windows 上没有命令沙箱。核实符合权限的只读命令可以直接运行。普通命令通常会问你，除非你已同意在开启 YOLO 的话题里自动运行普通命令。
- **Bot 的浏览器**：和你自己的浏览器完全分开，没有你的登录；默认不能访问本机和内网地址。
- **操作电脑**：每个任务先弹授权卡；密码管理、终端和系统安全类应用一直不能操作；全局快捷键随时停止。
- **对外发送**：以你的身份发送（例如发邮件）每次都要你确认。
- **不可信内容**：网页、文件、模型输出都按不可信内容处理，不会被当成指令执行。

## 可追踪

![用工作收据核对 Bot 的操作、审批和交付](../images/zh/work-receipt.png)

- **工作收据**：每次运行列出读了什么、改了什么、跑了哪些命令、经过哪些审批、花了多少钱、哪些没核实。
- **操作记录**：每一次审批、执行和对外发送，只存在本机。
- **改动面板**：所有文件改动可以逐行查看、撤回；改动前会自动保留检查点。

## 完全离线使用

在欢迎流程或 设置 › 模型与密钥 里选择本地模型（如 Ollama），并在 设置 › 权限 里把「访问网站」设为「不允许」、关掉「Bot 跑的命令可以联网」，对话和文件就不会离开这台电脑。
