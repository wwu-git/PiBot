# 对外连接清单

[English](../en/outbound-connections.md)

这一页列出 Pi Bot 可能发起的全部网络连接，包括桌面应用、安卓手机 App 和执行端。每一项都写明：发给谁、发什么、什么时候发、默认开不开、怎么关。清单按源代码整理（Pi Bot 0.0.3）；以后哪个版本新增或改动了对外连接，这一页会在同一个版本里更新。

## 先说结论

- **不加遥测。** Pi Bot 没有统计分析、不跟踪使用情况、不自动上报崩溃，也不需要注册 Pi Bot 账号。反馈问题只能由你自己发出（见[问题反馈](#问题反馈)）。
- **你的内容留在你的电脑上。** 聊天、文件、记忆、设置和密钥都存在本机。只有为了完成手头的工作，内容才会发给你选定的服务：模型厂商、搜索服务、Bot 打开的网站，以及你连接的应用和 MCP 服务器。
- **Pi Bot 自己的服务器收不到你的聊天和文件。** 这些服务器是 `pibot.space`（更新）、`roles.pibot.space`（角色库）、`relay.pibot.space`（手机和执行端的中继，端到端加密）和 `auth.pibot.space`（只用于 Gmail 的 Google 授权）。
- **内置的第三方组件不往外发东西。** Pi Bot 内置的 pi 内核关掉了模型目录下载、版本检查和遥测；操作电脑用的驱动也关掉了遥测和更新检查。

## Pi Bot 自己的服务器

### 检查更新

- **接收方：** `pibot.space`（`/updates/` 提供版本信息，`/downloads/` 提供更新包）。
- **发什么：** 一次普通的请求，读取最新版本信息。User-Agent 里只有应用版本、操作系统和 CPU 类型，例如 `PiBot/0.0.3 (darwin; arm64)`。更新组件本来会带一个固定不变的随机 ID，Pi Bot 把它换成了全零的固定值，所以没法把请求对应到某一份安装。服务器只按天统计各版本、各平台的检查次数，除此之外什么都不留。和所有网站一样，它能看到你的 IP 地址。
- **什么时候：** 应用启动约一分钟后查一次，运行期间每 4 小时查一次；你点「检查更新」时也会查。只有你点「更新」才会下载，重启或退出时才安装。
- **默认：** 安装版默认开启。
- **怎么关：** 自动检查没有开关。它只读版本信息；如果你一个请求都不想有，可以在防火墙里屏蔽 `pibot.space`，以后自己下载新版本安装。

**安卓手机 App（从 0.0.4 起）。** App 向 `https://pibot.space/updates/android.json` 发送普通的 HTTPS GET，不带账号、设备或安装标识。服务器能看到你的 IP 地址。自动检查默认开启，在应用启动时检查，每天最多一次。你也可以在「设备」页手动检查。离线模式会跳过这些检查。只有你选择「下载并安装」，App 才会从 `pibot.space` 下载 APK。

### 角色库

- **接收方：** `roles.pibot.space`。
- **发什么：** 请求带签名的角色和群模板列表，以及你要安装的包。不带 Cookie、账号或任何标识。Pi Bot 先用内置在应用里的公钥校验列表签名，再按列表核对每个包的大小和 SHA-256，校验通过才使用。
- **什么时候：** 只在你点「检查角色库」或「刷新角色库」、从角色库安装或更新角色和模板，或者打开一个本机缓存列表里还没有的角色版本链接时才连。打开角色选择器本身不联网。
- **默认：** 你做这些操作之前不会发请求。
- **怎么关：** 不用角色库就行；内置的角色和模板不依赖它。

中继（`relay.pibot.space`）和 `auth.pibot.space` 分别见[手机和执行端](#手机和执行端)和 [Gmail](#gmail)。

## 模型

### 模型厂商

- **接收方：** 你在 设置 › 模型与密钥 里配置的厂商：OpenAI、Anthropic、Google、DeepSeek、OpenRouter、云平台（Amazon Bedrock、Azure、Google Vertex AI、Cloudflare）、自定义网关等。每个 Bot 可以用不同的厂商。
- **发什么：** 模型回复需要的内容：对话、Bot 的人设和指令、用到的记忆、Bot 读到的文件片段和网页内容、工具结果，以及你附上的图片。API Key 只发给对应的厂商。请求里会注明应用名「Pi Bot」（和网址 pibot.space），供厂商做应用归属统计，不加任何用户标识。对支持的厂商，Pi Bot 会请求延长提示缓存（部分 OpenAI 模型最长 24 小时，Anthropic 1 小时），让回复更快、更省钱；这部分缓存按厂商自己的条款处理。
- **辅助模型：** 整理上下文、交接、翻译、写人设草稿、提炼网页或从对话提炼记忆时，相关内容会发给辅助模型的厂商。默认跟随主模型。
- **什么时候：** Bot 每次回复或用到模型时。「保存并测试」会发一条很短的测试请求；「获取模型列表」会向该厂商（或你填的自定义地址）读取模型列表。云平台还会连它们自己的认证服务，比如 Google Vertex AI 会连 `oauth2.googleapis.com`。
- **OpenRouter 模型列表：** 在 OpenRouter 页面点「刷新模型列表」，会从 `openrouter.ai` 下载公开的模型列表，不带你的 Key。
- **默认：** 配好模型之前什么都不发。
- **怎么关：** 用本地模型。Ollama、LM Studio、vLLM 都在你的电脑上运行，Pi Bot 通过 `127.0.0.1` 连接它们，数据不出电脑。欢迎流程会在 `127.0.0.1:11434` 查找 Ollama，同样只在本机。
- **代理：** 在 设置 › 通用 › 网络代理 里填了代理后，所有厂商请求都走这个代理（本机的模型服务除外）。Pi Bot 不会自己去用系统代理。

### ChatGPT 计划

- **接收方：** 两种方式都用 `auth.openai.com` 登录和刷新令牌。使用「ChatGPT 计划」模型会向 `api.openai.com` 发请求，使用「ChatGPT（Codex 登录）」模型会向 `chatgpt.com` 发请求。
- **发什么：** 你在 OpenAI 的网页上登录。使用模型时，模型需要的对话内容直接发给 OpenAI。登录令牌加密保存在这台电脑上。
- **什么时候：** 你主动登录、使用已登录的模型，或应用刷新登录时。
- **怎么关：** 在「模型与密钥」打开对应的订阅，点「断开」。两种登录可分别断开。

## Bot 干活时的连接

### 联网搜索

- **接收方：** 设置 › 模型与密钥 ›「联网搜索」里选的服务：
  - **免 Key（自动）**（默认）：先用 DuckDuckGo（`html.duckduckgo.com`），连不上时换 Bing（`cn.bing.com` 或 `www.bing.com`）。
  - 单独选 **DuckDuckGo** 或 **Bing**。
  - **Brave Search API**（`api.search.brave.com`）或 **Tavily**（`api.tavily.com`），需要填你的 API Key。
  - **自建 SearXNG**：只连你填的地址。
- **发什么：** Bot 写的查询词；用 Brave 或 Tavily 时还有你的 Key。
- **什么时候：** Bot 联网搜索时。免 Key 服务第一次使用会在聊天里问你。
- **怎么关：** 在 设置 › 权限 里把「访问网站」设为「不允许」（可以对全部 Bot，也可以只对某个 Bot），搜索也会一起被拦下。

### Bot 访问的网站

- **接收方：** Bot 打开的网站，不管是用它自己的浏览器打开，还是直接抓取网页。
- **发什么：** 普通的网页请求。Bot 的浏览器和你自己的浏览器完全分开，没有你浏览器里的登录；只有你替它登录过，或者用你保存的账号，它才是登录状态。每个网站第一次自动登录、第一次提交表单都会先问你。默认不能访问本机和内网地址。
- **Pi Bot 浏览器扩展：** 装了扩展（Chrome、Edge 或 Firefox）后，Bot 可以在你自己的浏览器里干活，用的是那个浏览器里的登录。扩展只通过浏览器的本地消息通道（native messaging）和桌面应用通信，不往 Pi Bot 的服务器发任何东西；安装和更新由浏览器的扩展商店负责。
- **聊天里的图片：** 回复里引用的网络图片不会自动加载，你点一张才下载那一张。
- **默认：** 允许。
- **怎么关：** 在 设置 › 权限 里把「访问网站」改成「询问」或「不允许」。

### Bot 跑的命令

- **接收方：** 软件包仓库（`registry.npmjs.org`、`pypi.org`、`files.pythonhosted.org`）、「允许的网站」名单里的网站，以及你自己配置的服务器：命令环境里的 SSH 主机，还有你在改动面板里推送或拉取时的 Git 远端。
- **发什么：** 命令自己发的内容。macOS 和 Linux 上命令在沙箱里运行：不经询问自动运行的命令只能访问软件包仓库和你的名单；打开「Bot 跑的命令可以联网」后，你批准的命令可以更自由地联网。Windows 上没有命令沙箱。确认符合权限的只读命令可以直接运行，用户同意后，开启 YOLO 的话题也可以自动运行普通命令。命令本身的联网不受沙箱名单限制。
- **默认：** 开启，但受上面的限制。
- **怎么限制：** macOS 和 Linux 上可关闭「Bot 跑的命令可以联网」，收紧沙箱内命令的联网。Windows 上可按需撤回 YOLO 命令同意，或限制「运行命令」。详见[审批与权限](../../guide/zh/05-approvals-and-permissions.md#命令隔离沙箱)。

## 应用、MCP 和技能

### MCP 服务器和连接的应用

- **接收方：** 你连接的服务。
  - **用网址添加的 MCP：** 就是那个地址；如果它需要登录，还有它的登录页面。
  - **用 `npx` 或 `uvx` 启动的 MCP：** 第一次启动时从 `registry.npmjs.org` 或 PyPI 下载软件包。之后它在沙箱里运行，只能访问它声明的域名。
  - **Notion：** Notion 官方托管的 MCP 服务（`mcp.notion.com`），你在浏览器里登录 Notion。只读。
  - **本机日历、本机通讯录、Obsidian：** 在本机读取，不联网。
- **发什么：** 每次调用这个服务需要的内容。写入和对外发送每次都要你确认。
- **什么时候 / 默认：** 只有你添加了连接并把它给了某个 Bot 之后。「从其他 AI 工具带过来」只读本机上的配置。
- **怎么关：** 删除这个连接，或者从 Bot 那里收回。

### Gmail

当前发布版还没有 Gmail 插件；下面是它发布后的连接方式，现在不会发生。

Gmail 插件有两种登录方式：

- **Google 授权：** 你在系统浏览器里登录 Google。Google 要求用一个客户端密钥换取令牌，而桌面应用没法把密钥藏住，所以换令牌这一步经过 Pi Bot 的授权服务 `auth.pibot.space`：
  - 连接时，Pi Bot 把授权参数发给 `auth.pibot.space`：申请的权限范围、一次性的 PKCE 校验码和本机回调地址（`127.0.0.1`）。刷新令牌返回时用只有你电脑才有的密钥加密。
  - 插件每次使用 Gmail 时，把你的刷新令牌和客户端 ID 发给 `auth.pibot.space`，换一个短时有效的访问令牌。访问令牌不落盘。
  - 邮件本身直接在你的电脑和 Google（`gmail.googleapis.com`）之间传输，`auth.pibot.space` 看不到邮件内容。
- **应用专用密码：** Pi Bot 直接连 `imap.gmail.com` 和 `smtp.gmail.com`，不经过任何 Pi Bot 服务器。
- **默认：** 你连接 Gmail 之前不会连。
- **怎么关：** 在插件里断开 Gmail：令牌直接向 Google（`oauth2.googleapis.com`）撤销并从本机删除。也可以改用应用专用密码。

### 技能

- **从链接导入：** 从你粘贴的链接下载：GitHub 仓库会连 `github.com`、`codeload.github.com` 和 `api.github.com`，`.zip` 链接就连它所在的网站。从来源检查技能更新时连的也是这些地方。
- **准备运行环境**（技能带 Python 或 Node 脚本时）：经你同意后，Pi Bot 从 GitHub（`github.com` 及 GitHub 的文件服务器）下载固定版本的 uv 并校验 SHA-256，再用它从 GitHub 下载 Python、从 PyPI（`pypi.org`、`files.pythonhosted.org`）下载技能需要的包。Node 包从 `registry.npmjs.org` 下载。
- **发什么：** 普通的下载请求，不含你或你文件的任何信息。
- **什么时候 / 默认：** 只在你导入、检查更新或准备运行环境时。

### 外部 Agent

- **Codex 和 Claude Agent：** 你点「下载并创建」时，Pi Bot 从 `registry.npmjs.org` 下载固定版本的 ACP 适配器，每个文件都校验 SHA-256。
- **运行时：** 外部 Agent（Codex、Claude Agent、Cursor、OpenCode）以 Bot 身份加入后，用它自己的账号连它自己家的服务，例如 Codex 连 `api.openai.com` 和 `chatgpt.com`，Claude 连 `api.anthropic.com` 和 `claude.ai`，Cursor 连 `cursor.com`，OpenCode 连 `opencode.ai` 和你在 OpenCode 里配置的厂商。macOS 和 Linux 上，Pi Bot 把每个 Agent 限制在它自家的域名里。它发出的内容按各家自己的条款处理。
- **默认：** 你添加之前不会连。

## 手机和执行端

### 中继

- **接收方：** 官方中继 `relay.pibot.space`（运行在 Cloudflare 上），或者你自建的中继（见[自建中继](../../guide/zh/15-self-hosting-relay.md)）。
- **发什么：** 电脑、已配对手机和执行端之间端到端加密的数据；中继读不到内容，也不保存聊天。它能看到 IP 地址、连接时间、帧大小和哪些设备在线。官方中继只按天、按设备类型（电脑、手机、执行端）统计连接次数，不记房间号、设备和 IP。
- **什么时候：** 打开「允许已配对设备连接」（设置 › 设备）期间，以及配对时。执行端连它配对时用的那个中继。
- **默认：** 关闭。
- **怎么关：** 关掉「允许已配对设备连接」，或者在「高级」里换成自建中继。

### 直连（STUN）

- **接收方：** STUN 服务，默认是 Cloudflare 的 `stun:stun.cloudflare.com:3478`。
- **发什么：** 电脑和手机（或执行端）各发一次很小的 STUN 查询，得知自己的公网 IP 和端口，以便尝试直接连接。STUN 只看到这个公网地址，从不经手聊天、文件或其他数据。
- **在同一个局域网里：** 设备之间用 mDNS（「局域网发现」）互相找到并直接连接，这部分流量不出你的局域网。用 `--listen` 启动的执行端也可以通过这个地址直接连上。
- **什么时候：** 远控打开、设备连接时。
- **默认：** 「直连方式」默认是「允许打洞」；配对手机前你确认的说明里写明了这一点。
- **怎么关：** 在 设置 › 设备 ›「高级」里把「直连方式」改成「仅局域网直连」：设备只在同一网络里直连，其余情况走中继。也可以填你自己的 STUN 地址。「局域网发现」也可以在这里关掉。

### 手机通知

- **接收方：** Expo 的推送服务（`exp.host`），以及安卓上负责投递通知的 Google Firebase 云消息（FCM）。
- **发什么：** 手机向 Expo 申请一个推送令牌。当有 Bot 需要审批、任务完成或失败时，电脑请中继经 Expo 发一条推送，内容只有一句固定的话（「有 Bot 需要你审批」「任务已完成」「任务未完成」）和一段只有你的手机能解开的加密引用，不含聊天、审批内容或 Bot 的输出。电脑需要用到手机的能力时，也用同样的方式发一条不显示文字的推送来唤醒手机 App。
- **默认：** 只有你在手机上允许通知时才有。
- **怎么关：** 在手机系统设置里关掉 Pi Bot 的通知，或者解除配对。

### 手机离线回复

- **接收方：** 你允许的每个 Bot 所用的模型厂商，由手机直接调用。
- **发什么：** 和电脑上同类的内容：对话、Bot 的人设，以及你选中的记忆。只有你开启后，模型 Key 才会同步到手机。手机的隐私账本会列出每次请求（哪个厂商、哪个模型、几条消息，不记内容）。
- **什么时候：** 只在电脑离线时。
- **默认：** 关闭；要在 设置 › 设备 › 这台手机 ›「电脑离线时」里逐台开启。
- **怎么关：** 在同一处关掉，或者撤销、解除配对这台手机，手机上的 Key 会被删除。

## 问题反馈

- **在 GitHub 打开**（左下角头像 ›「问题反馈」）会在你的浏览器里打开 Pi Bot GitHub 仓库的一份预填 Issue。链接里只有你写的标题和描述、应用版本和操作系统。在你自己到 GitHub 上提交之前，什么都不会发出。
- **导出日志** 把脱敏后的日志存成本机文件，不含聊天正文、文件内容和密钥；发不发给别人由你决定。

## 其他

- **你点开的链接：** 官网、「前往下载」、浏览器扩展商店页、厂商注册页、ChatGPT 计划的「管理用量」等按钮，都在你的默认浏览器里打开，而且只在你点击时。
- **拼写检查词典：** 在 Windows 和 Linux 上，应用输入框自带的拼写检查（Electron 提供）可能会从 Google 的服务器下载你所用语言的词典，请求里只有词典文件名。macOS 用系统自带的拼写检查。
- **沙箱自检：** 用 `--sandbox-doctor` 运行应用（见[审批与权限](../../guide/zh/05-approvals-and-permissions.md#沙箱自检)）会向 `example.com` 和 `example.org` 发测试请求，不含聊天、文件内容或密钥。

## 完全离线使用

选用本地模型，把「访问网站」设为「不允许」，关掉「Bot 跑的命令可以联网」，对话和文件就不会离开这台电脑。桌面端检查更新，以及你主动发起的操作（角色库、导入技能、插件），仍会按上面说的方式联网。详见[隐私与安全](../../guide/zh/13-privacy-and-security.md#完全离线使用)。
