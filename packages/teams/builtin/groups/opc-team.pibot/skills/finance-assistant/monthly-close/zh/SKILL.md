# 月度记账与对账

流水：{流水}　票据：{票据}　月份：{月份}

## 步骤
1. 先看文件：列出读到的每个文件、行数、日期范围和币种；表头不清楚的先说明自己怎么理解每一列。原件只读不改。
2. 记账：每笔流水一行，字段为日期、对方、摘要、收入、支出、币种、类别、来源（文件名 + 行号）。类别用老板已有的分类；没有时用：营业收入、软件订阅、外包、广告、办公、税费、转账、其他。
3. 转入转出自己的另一个账户记为「转账」，不算收入或支出。
4. 对账：以流水为准，逐笔找对应的发票或收据（金额、日期前后 7 天、对方三项对上才算匹配）。
5. 核余额：期初余额 + 收入 − 支出 = 期末余额。对不上就写差额，并列出可疑行（重复、退款、手续费、跨月）。
6. 行数很多时可以请求运行只读的汇总命令（只读输入、不联网、结果写新文件），说明用途后等确认；也可以用内置 Office 工具写带公式的表格。
7. 只出报告：需要付款、补开发票、退款的事列进「需要你处理」，由老板本人操作。

## 交付
在本次产物目录写两份文件：
- `账本-<月份>.xlsx`（或 CSV）：上面的字段，一行一笔。
- `月结-<月份>.md`：

```
# 月结 <月份>
数据期间 / 来源文件 / 生成日期

## 收支汇总
| 类别 | 收入 | 支出 | 笔数 |

## 余额核对
期初 … + 收入 … − 支出 … = … ；流水期末 … ；差额 …

## 未匹配
| 日期 | 对方 | 金额 | 缺什么 | 来源行 |

## 需要你处理
- …
```

## 核对
- 账本行数等于各来源文件的流水行数之和（排除表头和汇总行，注明排除了几行）。
- 差额为 0 才能写「余额已核对」；否则写实际差额。
- 卡号、账号只保留后四位。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
