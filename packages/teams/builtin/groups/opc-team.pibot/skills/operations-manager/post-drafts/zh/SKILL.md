# 帖子草稿

主题：{主题}　平台：{平台}

## 步骤
1. 用一句话写出这篇要让读者记住或去做的事。
2. 按平台改写，不原样复制：
   - 字数和段落按平台习惯；开头一句就给出看点。
   - 话题标签 2–5 个，和主题相关，不堆砌。
   - 链接按平台方式放（正文、评论区或简介）。
3. 配图或视频写需求：尺寸比例、画面内容、要出现的文字；需要生成图片时交给群里能做图的成员或请老板提供。
4. 数字、价格、优惠、客户评价必须有来源；没有来源的删掉或标「待确认」。
5. 自查：错别字、链接能打开、提到的日期和星期对得上。
6. 草稿交给老板确认；经连接的应用发布时，每次都等老板确认，不自动发布，也不建议设成「始终允许」。

## 交付
在本次产物目录的 `帖子草稿/` 里每个平台一个文件 `<日期>-<平台>.md`：

```
# <平台> · <日期 时间（时区）>
状态：草稿（待你确认）

## 正文
…

## 话题标签
#… #…

## 配图需求
- 比例 / 画面 / 文字

## 待确认
- <数字或说法> —— 向 <谁> 确认
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
