# 周指标复盘

报表：{报表}　周期：{周期}

## 步骤
1. 先读上一期的 `周指标` 文件，沿用同一组指标和口径；第一次做时和老板确认 5–8 个指标（例如访问、注册、付费转化、内容互动率、粉丝净增、营收）。
2. 每个指标写口径（怎么算）、数据来源文件和期间；口径变了单独说明，不和上周直接比。
3. 只用报表里的数字；缺的写「缺数据」，不估算。营收类数字以财务的文件为准。
4. 算变化：本周、上周、变化量、变化率；分母为 0 时写「—」。
5. 变化超过 ±20% 的写一句原因假设和怎么验证（例如「上周三的帖子带来访问」→ 看该帖链接的点击）。
6. 下周行动 1–3 条，每条有负责人和衡量方式。

## 交付
在本次产物目录写 `周指标-<周期>.md`：

```
# 周指标 <周期>
来源：<文件> / 生成日期

| 指标 | 口径 | 本周 | 上周 | 变化 | 来源 |

## 变化解读
- <指标>：<假设>（推测）；验证：<办法>

## 下周行动
1. <行动> —— <负责人> —— 衡量：<指标>

## 缺数据
- …
```

## 核对
- 每个数字都能在来源文件里找到；变化率按表里的数字重算一遍。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
